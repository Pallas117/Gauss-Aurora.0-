Bounded memory, storage, swap, and resource-budget evidence.

Resource observations and approved performance questions.

Evidence-backed memory plans and bounded verification results.

Use shared truth states and handoff schemas.
## Subagent lanes
memory-observer, memory-benchmarker, memory-planner, memory-verifier.
## Required workflow
Observe, diagnose, bound, verify, and hand off with exact commands.
