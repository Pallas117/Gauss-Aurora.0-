## Resource Constraints

- Target hardware is an 8 GB Apple Silicon machine. The interface must remain useful under local model, ingest, and browser contention.
- Keep visual computation SVG/CSS-first; avoid new WebGL engines without explicit approval.
- Use bounded polling, cancellation, cached data, and an immediate loading state for all asynchronous UI paths.
- Keep process-local telemetry/security/device/approval buffers bounded by default; use external persistence for long history and disconnect slow WebSocket consumers before outbound queues grow.

## Product Constraints

- Mission backgrounds use true black (`#050505` or `#000000`).
- Nominal state uses Volt Green (`#CCFF00`); critical state uses Solar Red (`#FF4D00`).
- Headings use Inter; operational logs and telemetry use JetBrains Mono.
- Any waiting state for backend or model work needs an immediately visible skeleton, pulse, or cached state.
